# Tug 0.8.20

## Join and arcs

- Arcs now show readiness based on whether their audit is still fresh — if the underlying code or base moves out from under an approved arc, it goes back for re-checking automatically instead of silently landing stale work.
- The Changes panel now opens up whenever an arc needs your attention — not just when it's ready to join — and shows exactly what's blocking it, one file per line.
- While a join is reconciling, you can now see what's happening step by step in a live log, instead of a bare spinner.
- Joining is faster: the extra pre-join test run that could get stuck behind busy machines is gone, replaced by a clear "last verified" status shown before you join.
- Removed the "Join" button on the finished-arc summary row — join from the other spots where it still belongs.

## Editing and selection

- Shift-arrow selection now works correctly after a mouse drag: it extends or shrinks from where you'd expect instead of jumping around.
- `Cmd-A`, Find (`Cmd-F`), and text selection now work in read-only documents like the transcript and the new Help windows.
- Help menu: added **Tug Help** and a **Glossary**, and the Overview can now answer questions about how Tug works, with links into the help text.

## Performance and polish

- Cards you switch away from stay loaded longer (up to two hours) before being freed, so switching workspaces back and forth is snappier.
- Long-running background commands now show up properly in the Jobs list and keep reporting their status instead of appearing stuck.
- Smoother card resizing in a few more cases, and several small visual fixes (toast notifications no longer hide behind side panels, selectable help text, clearer rate-limit notices).
- Various wording improvements so the app speaks in plain terms rather than referring to itself as "Tug."
