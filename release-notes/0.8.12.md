# Tug 0.8.12

Cutting a release is now a single command, `just release`, that walks the whole process — bumping the version, drafting notes, pushing, and shipping — and asks before every step that changes anything.

Releasing is no longer something the app does. The in-app release checklist and related controls have been removed from Tug; releases happen from the command line now. The `/push` gesture for sharing work in a session stays as it was.
