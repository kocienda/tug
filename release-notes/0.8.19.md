# Tug 0.8.19

## Every card is now its own web view

This release rebuilds how Tug draws the deck. Until now the whole deck — every card, every transcript, every sidebar — was one web page running on one thread. Everything that happened anywhere in the app competed for that one thread: a long transcript streaming in, a fold or a column move animating, a dot pulsing on the Overview, all of it queued behind the same door. Six earlier rounds of work had taken as much off that thread as could be taken, and the remaining cost was the engine's own: style, layout and compositing for one document that grew all day. There was no lever left to pull inside a single page.

So the deck is no longer one page. It is a thin shell page that draws the canvas, the rails and the layout, and over it stands **one web view per card, each in its own WebKit process on its own thread**. The host app places those views, stacks them in the deck's order, and runs every card motion — folds, unfolds, column splits and stacks, flow slides, resize-to-fit, drags — as Core Animation on the card's container, on the render server's clock. A card's content takes its final size before a single frame is drawn, so nothing relayouts mid-motion and the landing has nothing left to fix up.

What that means for you:

- **A busy card cannot slow another.** Three sessions streaming at once no longer compete with the card you are typing in, and a card's own heavy work (a huge transcript, a big diff) is paid in its own process.
- **Motion is smooth whatever the app is doing.** Card animations are driven by the host, not by the page, so they hold display rate even while a card's page is stalled.
- **Hidden cards go to sleep.** A card you cannot see stops listening to its session and stills its motion; after fifteen minutes hidden, or at once under memory pressure, it gives up its process entirely. The card stays in the deck with its session, binding and draft untouched, shows its real phase the whole time, and comes back under its own last frame when you return to it — no blank, no flash of canvas.
- **Parked workspaces cost nothing.** A workspace you have not visited since launch loads none of its cards until you switch to it, and when you create a workspace or switch between them the new arrangement lands in a single cut.
- **Crashes are contained.** If one card's page fails, only that card says it needs reloading; the rest of the deck is untouched.

Everything you already use inside a card — selection, copy, find, scrolling, the composer, every chord and menu item, theme and zoom, VoiceOver — works as before. The one deliberate change: you can no longer drag a text selection across two cards, since each card is now its own document.

## Session card

- The TIME popup breaks a session's time into working, waiting on you, and offline, and shows the turn in flight alongside the finished ones.
- Choose Session lists sessions grouped by project, with the workspace's own projects first and open, so a new session starts where you are working. Double-click a row to open it.
- Session ▸ Insert File (⇧⌘I) accepts several files at once and inserts them in order.
- Right-click a misspelled word in any text field to see corrected spellings, with Learn and Ignore.
- A card reloads its transcript from disk only for a named reason — launch, opening onto a session, or a tugcast restart. A plain reconnect keeps everything on screen and fills in whatever ran while the socket was down.
- Fixed sessions that stayed on "Working" or stuck at Stop after the turn had actually finished.
- Fixed a card losing a turn, a question dialog or re-showing a finished prompt when a replay landed over a live turn.
- Fixed sessions in a project being trashed when that project fell off the recent-projects list. Only your own trash gesture deletes a session now.
- Fixed a stray caret position after pasting, and a pasted atom chip leaving the old chip drawn underneath it.
- Long tool-call names in a block header are clipped with an ellipsis instead of painting over the timing.
- Tall popups under the masthead now paint whole over it rather than being cut off by the card.

## Bash blocks and test runs

- Long-running commands in a Bash block now show a run panel: a progress bar, one row per test file or unit, and the reds as they land, folded under the latest run when a step is retried.
- Any project's test runner can reach that panel — known runners are wrapped automatically, and a project can declare its own.

## Editing

- New Edit ▸ Quote (⌘') and Unquote (⇧⌘') add or remove a Markdown quote level on the selected lines.
- Astro files (`.astro`) get syntax highlighting and open as source.
- The File card paints selection across blank lines.
- The completion popup scrolls only itself to reveal the selected row, instead of dragging the card's content sideways.

## Layout and appearance

- A new **Gap** row on the Layout card sets the air between cards, with four presets. The default is now Roomy.
- Dragging a sidebar rail's width moves nothing until you let go: a translucent ghost shows the new footprint, and the release settles everything into place.
- Closing a card hands focus to the card you used most recently, not merely the nearest one.
- Workspace folds in the Cards card survive a relaunch, and folding a group in one workspace leaves it open in the others.
- Fixed grid lines dropping out on macOS 26.
- Fixed a system beep on the writing-direction chords ⌃⌘↓/←/→.

## Dialogs

- Confirmations are shorter and say plainly what will happen. Closing a card names its kind ("Close Session?"); logging out names your account and plan.

## Security

- A page open in your ordinary browser can no longer reach Tug's local API to read files, run code in the deck, or change state, and the host refuses file operations outside the folders each one needs.
- HTML rendered from model output passes a second sanitizer in the page under a Content-Security-Policy that permits no inline script.
