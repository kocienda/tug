# Tug 0.8.2

Updates are the theme of this one: they look different, they arrive sooner, and putting one off is now a real choice.

- **The update notice is yours to size.** An update arrives as a small badge in the corner of the window — or already open, if you asked for the check yourself. Collapse it and it waits as a badge until you are ready, so deferring an update is a decision rather than a dismissal. Open, it walks the download, unpack and install steps as they happen.
- **Updates arrive sooner.** Tug now checks for a new version every two hours while it is running, instead of once a day. A fix we ship should reach you within an hour or two, without quitting and relaunching.
- **New project commands show up right away.** A slash command added to a project's `.claude/skills` folder now appears in the `/` menu of a session you already had open, instead of being reported as unknown until the session's next turn.
