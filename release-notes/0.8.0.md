# Tug 0.8.0

The first release of Tug, an IDE for AI coding.

Tug puts shell commands and AI conversations in one place: a Session card, where you type a prompt or a command into the same box and read the results in the same transcript. There is no terminal window to keep beside it — the card is the terminal, and Claude works in it alongside you.

## What's in this release

- **Session cards.** Run commands, talk to Claude, and see every file it reads, edits and tests as a structured block rather than a wall of text.
- **Arcs.** Hand a piece of work to Claude as an arc — it plans, implements, and audits its own change on a separate branch, and you land it when you are satisfied.
- **Changes shade.** See what a session changed, draft the commit message, and land it from the card.
- **Themes.** Three dark and three light themes, tuned for contrast.
- **Updates that stay out of the way.** When a new version is ready, a pill appears in the window; open it to read what changed and install when you choose. No update dialogs.

Tug requires macOS 15 or later.
