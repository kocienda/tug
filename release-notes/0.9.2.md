# Tug 0.9.2

This release polishes the session picker, drag-and-drop composer focus, and help docs, with a theming audit that fixes several broken color tokens.

## New

- A new Getting Started help card (Help ▸ Getting Started) walks through prompting, monitoring, reviewing and committing — it opens automatically the first time you set up a session.
- The session picker now shows a Create button when a chosen directory doesn't exist yet, so you can create it on the spot instead of hunting for it in Finder.

## Improved

- Dropping a jot onto the composer now keeps your caret in place and focuses the composer, so you can immediately send it.
- The session menu now shows a dimmed "Current Session" entry when you open it on the session's own card, instead of no row at all.
- The active workspace in the Cards card is now marked only by its eye glyph; the name no longer gets a distracting accent color.
- Shell commands assembled from a simple variable (like `d=/tmp/x && rm -rf $d`) are now recognized correctly instead of being blocked.
- Declined tool calls are now shown as "steered" with a clear explanation, instead of looking like an error.
- Help documentation now spells out keyboard shortcuts (e.g. "Command-N") instead of using symbols, for clarity.

## Fixed

- Fixed several incorrect color references across the app (popups, progress bars, cards, sheets) that could cause elements to render with the wrong color in some themes.
