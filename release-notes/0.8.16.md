# Tug 0.8.16

## Highlights

- Fold any card — not just Session cards — down to a slim title strip with `⌃⌘Y`, the title bar's fold button, or View ▸ Fold Card. Great for packing a wall of files and sessions into less space.
- `/cd <directory>` moves a Session card to a different project folder while keeping its conversation and prompt history intact.
- Speak into any composer: a microphone button sits next to Submit, `⌘D` starts and stops it, and `⇧⌘D` finishes dictation and sends. Dictation runs entirely on your Mac.
- Each workspace can now have its own theme, and switching workspaces is noticeably snappier.
- Ten themes, newly named for vessels — six familiar ones renamed, plus four new themes (Galleon, Collier, Kayak, Pinnace).

## Also in this release

- Dragging a sidebar's edge now moves it live, with a width readout and a spring-back at its limits.
- The Workspaces card shows each workspace's theme as a swatch, and lets you pick a new theme right from the row.
- A new workspace opens with its name ready to type over; the delete confirmation now counts only that workspace's own cards.
- The `/usage` sheet shows which account you're signed in as.
- A session's permission mode (e.g. Plan Mode) now survives reconnects instead of silently reverting.
- Quoted text pasted into a prompt ("> like this") is no longer mangled.
- Fixed a jot editor opening with a snap instead of a smooth slide, and a few drag-and-drop and scrolling glitches in the Jots card.
- The model picker folds older model versions behind a "Show older models" toggle.
- The update window's progress bar no longer shifts the rest of the dialog around while it's working.
- Requires Claude Code 2.1.285 or later.
