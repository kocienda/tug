# Tug 0.8.21

A new Data Visualization sheet charts your project, the Overview answers "how do I…" questions directly, and a join now refuses work its audit does not cover.

## Charts

- A new Data Visualization sheet (Control-Command-V, or the end of the Session menu) shows every built-in chart — commits, churn, hotspots, test health, arc timelines, token usage, and more — each with a thumbnail and a one-line description of what it tells you. Pick one to draw it, or just ask for a chart in plain language and Tug will find the right one.
- Charts now draw in Tug's own look, matching whatever theme you're using, including colorblind-safe palettes. Hovering a chart shows the exact values under your cursor.
- Mermaid diagrams are gone — charts render as native Tug graphics everywhere instead.
- Bash output with a chart in it now shows the chart even while the terminal block is collapsed.

## Help

- Asking the Overview "how do I…" now gets a direct, step-by-step answer for dozens of common tasks — including what you'll see and when something isn't possible — rather than a vague pointer to a document.
- The Overview can now also search and reference your session transcripts, past notes, and project documents when answering questions, not just the help pages.

## Arcs

- Landing an arc now checks that its audit still covers it. If rounds landed since the audit ran, the base moved, or no audit has run yet, the join refuses and says why.

## Fixes and small changes

- Fixed a case where closing a Session card while a command was running could leave that command (and Claude) still running in the background.
- Fixed new cards sometimes opening under or overlapping the side rails.
- Fixed a case where text could lose its selection position after certain window changes.
- Fixed the caret and line numbers drifting out of alignment with the code when the window is zoomed to something other than 100%.
- Fixed a case where the Overview could stop following new output early and never resume.
- You can now fold and unfold a project's sessions in the Choose Session list with Command-Left Arrow and Command-Right Arrow.
- The update download button is now labeled "Pause" instead of "Stop for Now."
