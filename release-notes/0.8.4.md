# Tug 0.8.4

The way Tug updates itself is rebuilt, and jots get a right-click menu.

- **One update dialog.** When a new version is available, a small notice appears at the top centre of the window and says so — nothing more. Click it, or choose **Check for Updates…** from the Tug menu, to open a step-by-step update dialog: check, download, install and relaunch. Close it at any point and come back later; a download in progress keeps going while it is closed, and the dialog reopens on whichever step it has reached. The notice has an `x` if you would rather not see it for now.
- **Installing never stops work without asking.** If any session is mid-turn when you press Install and Relaunch, Tug names them and asks before it stops them.
- **Right-click a jot.** Jot rows now have a context menu: Edit, Cut, Copy, Copy as Plain Text, Paste, New Jot, and Delete — each acting on the whole jot, not just the line you clicked.
