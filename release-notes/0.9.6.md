# Tug 0.9.6

Tug 0.9.6 brings an arc shade that shows where a piece of work came from, live activity across the Workspaces card, and a fix that carries your data forward from 0.9.5.

## Updating from 0.9.5

- 0.9.5 kept its data under the wrong name. On first launch, 0.9.6 moves your workspaces, sessions and settings back to where every later version will look for them, so nothing goes missing in the update.

## Arcs

- Pressing the ARC cell in a session's status row, or `⌥⌘R`, now raises an arc shade over the transcript in place of the old popup. With an arc bound it shows the arc's Sketch across the top and its Brief and Arc beneath, each sized to its content, and a panel expands when you click it. Escape, a second press or Done lowers it.
- With no arc bound, the shade explains what an arc is, offers a New Arc button, and lists the project's arcs that aren't bound to a session, each with a Bind button. New Arc is also in the Session menu.
- An arc's sketch now opens with what is wanted, in plain language, and then the shape of the work. When that work has a shape, the sketch draws it as a diagram.
- A joined or discarded arc now keeps its brief, plan and sketch, and every version of a sketch is kept. Arcs and sketches can be placed in a prompt as references, the way a session can.
- An arc's step count (`3/6`) shows only while its steps are running, and Workspaces rows no longer spell out the arc's phase.
- Repeat verification during an arc's audit skips checks that already passed on the same code, so a small fix re-checks only what it could have broken.

## Workspaces card

- A new View popup in the toolbar adds an Activity view: every session and file across all workspaces in one list, newest first, each marked with its workspace.
- Each card row now shows the same numbered slot badge as the card's masthead.
- Session rows are a steady three lines (name, a line with the arc or the session's facts and its activity tape, and the description), so binding an arc no longer changes a row's height.
- Activity tapes on the Workspaces, Overview and Arcs cards are live again. Every surface now draws the same tape for a session, including a card opened or woken mid-turn, and the tape shows the work a session's shell commands are doing, not just Claude's.

## Session card

- A command run from the Session card is no longer stopped at two minutes. If it goes quiet, its block asks whether it might be stuck and offers Terminate or Keep Waiting, and the command keeps running either way.
- A Session card that slept through the end of its turn no longer thinks the turn is still running and offers a Stop with nothing to stop.
- Tug now says how Claude Code is logged in (a Claude subscription, a Console profile, an API key, an auth token or an API key helper) and asks you to confirm before opening a session on a login billed per token. Logging out matches that login.
- Switching workspaces no longer shows a blank pane for a card that had already drawn.
- An attachment preview now rises from the bottom of the card, like the card's other sheets.

## Text card

- The Text card has a dictation mic and `⌘D`, and its status strip controls are larger.

## Other changes

- When macOS's shared graphics service for web content wedges, which stalls every app that draws web pages until the Mac restarts, Tug now says a restart is the fix instead of hanging on its splash screen, and no longer adds load to it.
- Report panel bands show passes and failures as their own segments, so one pass and one fail reads as half green and half red.
- In flow diagrams, lines go around boxes they don't connect to instead of through them.
