# Tug 0.9.3

This release adds sharing turns from a session, live project directories, and @ mentions of sessions and commits, makes workspace switching immediate, makes shortcuts follow your keyboard layout, and fixes a batch of bugs reported by people trying Tug for the first time.

## New

- **Share Turns.** A Session card can now hand part of its conversation to someone else. `/share`, File ▸ Share Turns…, or Share from Here… on a transcript row opens a shade at the bottom of the card: select the prompts, answers and shell exchanges you want, choose how tool calls appear (summaries, full, or none) and a format (PDF, image, or Markdown), then Preview, Copy, Save or Share. Secrets are removed and your home folder is shortened to `~` before anything leaves, and the PDF and image are drawn from the card's own transcript in your current theme.
- **Add Project Directory.** A session can now reach a second folder without leaving its own, the way `/add-dir` works in Claude Code in the terminal. Use `/add-dir`, Session ▸ Add Project Directory…, or the new folder-plus button in the session masthead. The folder is granted to the running session at once and kept across relaunches, a checkbox offers to include it in every future session for the project, and its files appear in `@` completion. `/remove-dir`, or the `x` beside a folder in the Session Summary, gives it back.
- **@ mentions of sessions and commits.** Typing `@` in the Session card or Overview composer now offers sessions and commits beside files. `@@` narrows to sessions and `@#` to commits.
- **Tooltip Delay.** Settings ▸ General ▸ Tooltip Delay sets how long a tooltip waits, from 0s to 0.7s, or Never. The default is now 0.2s, much quicker than before.
- **Rename a session from the session card masthead.** The pencil in the masthead's `⋯` controls, Rename Session… in the masthead's right-click menu, `/rename` and Session ▸ Rename Session… all turn the name into a text field in place. Return or clicking away commits and Escape cancels. The rename sheet is gone, and Rename Session… now sits at the foot of the session menu.
- **Name a workspace as you make it.** New Workspace and Duplicate Workspace now ask for the name first, in a dialog that zooms in from the control you pressed and out to the workspace's new row. The workspace loads behind the question, so committing the name lands on finished cards, and Cancel makes nothing.

## Improved

- Switching workspaces is immediate. The arriving workspace appears whole at once, with each card's live page, its last frame or a skeleton, and nothing of the workspace you left shows through afterwards. Switching between workspaces with different themes no longer flashes the sidebar in the departing theme.
- Copying a selection from a session transcript or the Overview card now gives plain text, ready to paste into a prompt, a message or an email. Copy as Markdown (Option-Shift-Command-C) takes the place of Copy as Plain Text there and copies the Markdown. The composer and Text cards are unchanged.
- Command-click now opens a file reference exactly as a plain click does: file paths in the transcript, a file block's header, and files in the Changes list.
- A tooltip now closes the moment the pointer leaves its control, so the tooltip for the neighbouring button appears instead of being held off by the old one.
- The Session Summary has a Project row and a Directories row, and each folder in them opens in Finder with a click.
- A new card opens in the first empty slot instead of stacking onto a card that is already there.
- The Session card's status row always shows an ARC cell, reading `None` when the session drives no arc, so the row no longer rearranges itself. The little-used `/tasks` command and its checklist are gone.
- Session rows in the Workspaces card now say an arc's phase in words (Executing, Auditing, Stopped) beside its glyph.
- A re-audit now shows its progress. When a commit landing on the base branch makes a finished arc's audit stale, the card holding that arc shows the re-audit as one live block in its transcript: what moved the base, each check as it runs and how it came out, and the verdict. If the re-audit has to wait, the block says what it is waiting for, and the ARC cell reads Re-auditing or Waiting throughout.
- When the AI mentions another session in a reply, it now writes the name in a form the transcript recognizes (`project/callsign`, or the session's id), so the mention appears as a live session reference instead of plain text.
- The Split or Stack Slot and Move Card commands have moved from the Window menu to the View menu, and say "Slot" where they used to say "Column".
- The installer disk image's background leaves room for whatever Finder draws around the window, so its text is no longer covered.
- The Delete Workspace confirmation wraps onto two lines instead of stretching to fit a long workspace name.

## Fixed

- Keyboard shortcuts now follow your keyboard layout. On AZERTY, QWERTZ, Dvorak and other non-QWERTY layouts a shortcut fired on the key at the US position, so Command-A could quit the app. A letter or punctuation shortcut now answers to the key that types that character, as the menu bar already said. Number shortcuts stay on the number row's keys.
- Tug no longer claims the `.pxd` extension, which stopped Pixelmator Pro from opening its own documents. A Cython `.pxd` file still opens in Tug, which now decides by the file's contents.
- Session ▸ Add Working Directory…, a retired command that could crash the app, is gone. Add Project Directory takes its place and works. `/add-dir` now runs instead of only autocompleting.
- A commit message being written in the Changes tab no longer turns up in the Prompt tab, and no longer replaces the prompt you had typed, after a relaunch or a transcript reload.
- The loading wave on restoring cards now animates, and is drawn in the card's text color.
- A Session card in a workspace that was not on screen could come back as an empty frame. It now comes up in its own card.
- A Session card bound to an arc could flicker rapidly between bound and unbound.
- An arc stopped and resumed much later is no longer stopped again at once as "went silent", and its Resume offer is withdrawn as soon as the resume lands.
- A card closed from a split now disappears at once instead of lingering while the remaining card moves.
- The Usage sheet reads the tips newer versions of Claude Code print, and shows commands and paths in their own case.
- An empty composer could be drawn only as wide as its placeholder text.
- Alerts and setup dialogs can no longer be left stuck open by a stalled closing animation.
