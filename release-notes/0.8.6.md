# Tug 0.8.6

Installing an update works, and stopping your work is now a step you take rather than something the install does for you. If you are reading this in the update dialog, the first half is already proven.

- **Install and Relaunch installs and relaunches.** It had never done either: Tug was waiting for Sparkle to ask it to quit, and Sparkle was waiting for Tug to say it was ready, so the press did nothing and a second press said the update was no longer active. The wait is gone. Press the button and the new version comes up once this one has finished shutting down.
- **Stopping work in flight is its own step.** The update dialog now has four: check, download, stop work in flight, install and relaunch. The stop-work step names the sessions that are mid-turn and offers a **Stop Work** button, and *Install and Relaunch* does not appear until nothing is running. Stop the turns in the cards yourself and the step settles on its own; start a new one and the install button steps back until it is done. The install can never be what ended your work, because it is never offered while there is work to end.
