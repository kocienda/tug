# Tug 0.9.1

The inevitable *oops release* after cutting 0.9.0 yesterday evening.

This release fixes several keyboard and focus bugs in card editors and panes, and makes background sessions and stuck restores behave more sensibly.

## Fixes

- Escape now goes to the right place: it closes an editor's autocomplete or slash-command popup instead of being swallowed by the surrounding pane, and a masthead popover can be closed with the keyboard again.
- Running `/diff` a second time on the same file now brings the existing Diff card forward instead of opening a duplicate.
- Agent task reports now show the actual hand-back message instead of a generic placeholder.
- A session still working in the background keeps its running indicator instead of incorrectly showing as done; once it finishes, it's shown in green.
- The restore screen no longer gets stuck open for up to 20 seconds when a card is parked in the background or stalled — only cards you're actually looking at can hold it open.
- Fixed a case where new cards could lose track of their permission mode setting; new cards now consistently default to Auto.
- Fixed a styling bug where a progress gauge could render in black instead of its intended color on certain overlay screens.
