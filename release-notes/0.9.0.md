# Tug 0.9.0

This release is a broad one: sessions now read as Done when you weren't looking, switching workspaces is faster and steadier, and find and replace works everywhere you edit text.

## Bumped version number from 0.8.x to 0.9.x
- First beta release.

## Sessions and workspaces

- A session whose turn finished while you were looking at another card now shows **Done** — a filled, still dot — instead of looking like it's still running. Attending the session clears it.
- Clicking a workspace in the Workspaces card no longer makes the list jump: the row you clicked stays under your mouse after the switch, and a filter you type is shared across every workspace's card.
- Switching workspaces (or creating one) now shows a clean cut: the workspace you're leaving, then loading skeletons if needed, then the finished workspace — never a half-painted frame in between. Cards that are ready appear with their correct theme and focus state right away, since parked workspaces are kept as finished pictures rather than remade on every switch.
- A press on a Workspaces row or a Layout place now rings the target card's border immediately, instead of waiting for the UI to settle.

## Find and replace

- Find and Replace is now available everywhere you edit text — the Text card, and the composers in both the Session and Overview cards — not just the Text card.
- Replace and Replace All got their own toolbar buttons, menu items, and keyboard shortcuts (⌥⌘G, ⌥⇧⌘G), and they visibly refuse when there's nothing to replace.
- Tab now moves between the find and replace fields.
- The find count and replace controls now correctly follow the text as you type or as a document becomes read-only, and your typed replacement text is preserved across a quit.

## Editing

- A new **Text** menu (between Edit and Session) collects transforms that act on the text itself: case changes, line-comment toggling, converting soft wraps to real line breaks (and back), curly-quote conversion, quote-level adjustment, and removing invisible "gremlin" characters.
- `.heic`, `.heif`, and `.avif` images can now be dropped or pasted in as image attachments.
- Key shortcuts (⌘, ⌥, ⌃, ⇧, and the arrow/escape/delete glyphs) now render in a custom-cut typeface matched to the rest of the UI, instead of a mismatched system font.
- Quitting Tug (⌘Q or Quit Tug) now asks for confirmation if a session has a turn in progress, so you don't lose in-flight work by accident.
- `Replace All`'s button is now labeled clearly instead of just "All".

## Fixes

- Files changed by a session rooted in another project now correctly show up on this project's Changes shade, naming the session and project that changed them.
- Centered images in a card now split and scroll correctly when the card is divided.
- Fixed a case where WebKit's cache could serve a stale version of Tug's interface after an update; Tug now purges its cache at launch and recovers automatically if a stale asset is detected.
- Look Up (dictionary lookup) now works from inside card bodies and from background right-clicks, not just the foreground window.
- Tug can now open extensionless and otherwise-undeclared text files (like `Dockerfile` or `.ts` files) from the Open File dialog.
- Minor polish: Overview's empty state reads "None", the Overview column gains a Clear option, the Text card's status bar is reorganized with tighter spacing, and the status bar now shows counts for a text selection when one is active.
