# there. They are recorded rather than repaired because repairing them is its own
# piece of work — most re-point mechanically from `dash/<plan>.md` to

# that is NOT on this list fails the build, which is the whole point — the list
# freezes the debt that existed on the day the check landed and catches every new
# one from that moment. The assertion is two-sided: an entry whose target has
# since been created, or whose citing file no longer cites it, ALSO fails, and the
# fix is to delete the line. A stale allowlist is the same disease one layer up.
#
